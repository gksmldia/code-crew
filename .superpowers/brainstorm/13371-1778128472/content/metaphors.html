3가지 메타포 후보 — 참고 URL

"세션 = 공간, subagent = 그 안의 캐릭터들"을 표현하는 시각 메타포 3가지. 각 카드의 링크를 새 탭에서 열어보세요.

🏢

A. 빌딩 단면도 (Office Cross-Section)

창 = 빌딩, 세션 = 층/사무실, subagent = 그 사무실의 직원들. 엘리베이터로 위아래 이동, 각 층마다 다른 일이 일어남.

참고작

  • SimTower (Wikipedia) — 1994년 클래식, 2D 단면 빌딩
  • Project Highrise (Steam) — 현대적 후속작, 정교한 픽셀 단면

장점: 위계가 명확함(층 = 세션). 직장 메타포라 "AI가 일한다" 컨셉과 잘 맞음.
단점: 세로로 길어서 화면 비율이 어색할 수 있음.

🐜

B. 개미굴 단면도 (Ant Colony Cross-Section)

창 = 흙 단면, 세션 = 굴/방, subagent = 그 굴에서 일하는 일개미들. 페로몬으로 통신, 협업으로 큰 일 처리.

참고작

  • Empires of the Undergrowth (Steam) — 개미굴 단면 RTS, 압도적 긍정 평가
  • 공식 사이트 — 트레일러로 비주얼 확인

장점: "수많은 일꾼이 한 목표로 협업" 메타포가 멀티 에이전트와 가장 잘 맞음. 자연스러운 군중감.
단점: 어둡고 끈적한 톤. 데스크탑 펫의 가벼운 분위기와 안 맞을 수 있음.

🚀

C. 우주선 격실 (Spaceship Rooms)

창 = 우주선 단면, 세션 = 격실(엔진룸/함교/무기고), subagent = 그 방의 승무원. 위급 상황 = 빨간 경고등, 작업 중 = 콘솔 두드림.

참고작

  • FTL: Faster Than Light — Ship (Wiki) — 격실 레이아웃 이미지 다수
  • FTL Steam 스크린샷 갤러리 — 실제 게임플레이 비주얼

장점: 격실 = 명확히 구분된 작업 공간. 빨간 경고/녹색 OK 같은 상태 표시가 직관적. 테크 친화적 분위기.
단점: "팀 협업" 보다 "고독한 임무" 느낌. 한 격실에 보통 1-2명만.

셋 다 마음에 안 들면 다른 메타포 (예: 어항/수족관, 개미농장, 게임 길드 던전, 식당 주방, 우주정거장 등)도 가능해요. 편하게 알려주세요.
