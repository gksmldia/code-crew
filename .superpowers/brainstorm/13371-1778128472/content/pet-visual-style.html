1. 픽셀 아트 vs SVG 캐릭터

픽셀 아트 (Pixel Art)
🐶 🐱 🦊
16x16 / 32x32 sprite sheets
frame-by-frame walk/idle/work
레트로한 게임 분위기

예시 / 어셋 소스

  • itch.io 무료 픽셀 고양이
  • itch.io 무료 픽셀 강아지
  • itch.io 무료 픽셀 동물 전체
  • The Spriters Resource (참고용, 라이센스 주의)
  • OpenGameArt 무료 동물 스프라이트

스타일 참고작

  • Stardew Valley — 16x16 동물
  • Loop Hero — 단순한 픽셀 캐릭터
  • A Short Hike — 부드러운 픽셀
SVG / 벡터 캐릭터
벡터, 무한 확대 가능
CSS/JS로 직접 애니메이션
깔끔/모던한 분위기

예시 / 어셋 소스

  • IconScout Pets Lottie/SVG (2,215개)
  • IconScout 고양이과 (97개)
  • Vecteezy 무료 SVG 동물
  • LottieFiles — 검색 "cat", "dog"
  • DiceBear — 절차적 아바타 생성 (animals 스타일)

스타일 참고작

  • Discord Wumpus
  • Notion 일러스트
  • Duolingo Duo

픽셀 아트 장점

  • 레트로/펫 정체성과 잘 맞음 (Tamagotchi 감성)
  • 저해상도라 작은 카드에 디테일 살리기 쉬움
  • 무료 어셋 풍부 (itch.io)
  • 애니메이션 = 프레임 교체로 단순

픽셀 아트 단점

  • Retina/HiDPI에서 흐릿하지 않게 처리 까다로움 (image-rendering: pixelated 필수)
  • 크기 변경 = 픽셀 깨짐, 미리 사이즈 정해야 함
  • 새 동물 추가하려면 누군가 그려야 함 (Aseprite $20)

SVG 장점

  • 무한 확대 (Retina, 4K 다 쨍함)
  • CSS transform/transition으로 애니메이션 직접 제어 (말풍선 따라 표정 변경 등)
  • 색상 변경 동적 (다크/라이트 테마, 상태별 톤)
  • 파일 크기 작음 (각 펫 5-20KB)

SVG 단점

  • "펫 같은" 친근함 < 픽셀 (모던/디지털한 느낌)
  • 복잡한 애니메이션은 SVG 직접 그리기 어려움 → Lottie 도입 시 라이브러리 부담
  • 좋은 무료 어셋이 픽셀보다 적음 (대부분 일러스트/아이콘 톤)

개인적 추천: SVG로 시작 (작은 카드 사이즈 + 다크/라이트 테마 + 동적 표정 변경에 유리). 후에 픽셀 테마를 옵션으로 추가하는 식. 다만 "Tamagotchi 감성"이 핵심이면 픽셀.

2. 펫 매핑 (작업 종류별)

subagent가 어떤 작업을 하느냐에 따라 펫 종류가 달라져요. 메인 펫은 세션당 고정 (사용자가 고를 수도, 자동도 가능).

작업 종류 Hook 이벤트 제안 펫 왜?
파일 읽기Read🐱고양이 = 조용히 관찰, 책 옆에 앉음
파일 쓰기/편집Edit/Write🐶강아지 = 꼬리 흔들며 열심
명령 실행Bash🦊여우 = 빠르고 영리, 일 빠르게 처리
검색Grep/Glob🦝너구리 = 구석구석 뒤짐
웹 검색/fetchWebSearch/WebFetch🦉부엉이 = 지식, 멀리 봄
서브에이전트 분배Task🐰토끼 = 무리 짓고 분담
노트북 편집NotebookEdit🐹햄스터 = 작은 셀 채움
권한 요청 대기PermissionRequest🐧펭귄 = 정중히 묻는 자세
에러error🦔고슴도치 = 놀라서 웅크림
완료Stop🐶강아지 = 꼬리 흔들며 자랑
idle/sleepidle🐢거북이 = 느긋하게 쉼

이 매핑은 시작점일 뿐이에요. 다 마음에 안 드는 거 있으면 바꿔도 돼요. 메인 펫은 사용자가 직접 고르거나 cwd 해시로 자동 배정 가능.

4. 세션 닫힘 + 프로젝트 메모리

세션 종료 시:
  1. 카드 즉시 사라짐 (UI에서)
  2. 채팅 히스토리 → ~/.clawd-pet/projects/{cwd-hash}.json 으로 저장
     {
       "cwd": "/Users/dorothy/clawd-on-desk",
       "git_root": "/Users/dorothy/clawd-on-desk",
       "last_seen": "2026-05-07T13:45:00Z",
       "messages": [ ...최근 200개... ]
     }

같은 프로젝트에서 새 세션 시작 시:
  1. cwd → git_root 우선으로 매칭 (없으면 그냥 cwd)
  2. 해당 프로젝트의 messages 자동 로드
  3. 카드 헤더에 "이전 대화 N개 불러옴" 배너 (5초 후 사라짐)
  4. 새 메시지가 그 아래에 추가

매칭 우선순위:
  1순위: git remote URL 같음 (다른 워킹트리 / 클론에서도 같은 프로젝트로 인식)
  2순위: git root 경로 같음
  3순위: cwd 같음

저장 정책:
  - 메시지 최대 200개 (프로젝트당)
  - 보관기간 30일 (이후 자동 삭제, 설정 가능)
  - "이 프로젝트 기록 삭제" 메뉴 옵션

세션 ID는 매번 바뀌지만 cwd/git remote는 안정적이라 이게 자연스러운 키예요.

5. 사용자가 해야 할 것 (체크리스트)

디자인 확정 후 실제 만들기 전에 정해야 할 것들.

  1. 미적 방향 픽 (지금 이 단계)
    • 픽셀 아트 vs SVG vs 둘 다 (테마 토글)
    • 전체 분위기: 귀여움 / 미니멀 / 레트로 / 모던
  2. 어셋 소싱 — 결정한 스타일에 따라:
    • 픽셀이면: itch.io 무료팩 받거나, Aseprite($20)로 직접 그리거나, 픽셀 아티스트 발주 (Fiverr ~$30-100/캐릭터)
    • SVG면: Figma로 직접 그리기, IconScout/LottieFiles 유료 구독, 또는 일러스트레이터 발주
    • 최소 필요 펫: 8-10종 (위 매핑 표 참고) × 3-4 상태 (idle/working/happy/error) = 30-40 어셋
  3. 기술 스택 결정
    • Tauri (Rust+WebView, ~8MB) — Claude Pet 방식. 가벼움.
    • Electron (Node+Chromium, ~150MB) — Clawd 방식. 라이브러리 풍부.
    • 웹 only (브라우저 탭) — 더 가벼움, 데스크탑 펫 정체성 약화
  4. 프로젝트 이름 — `clawd-team`, `claude-zoo`, `pet-pack`, ...?
  5. 리포지토리 — GitHub repo 만들기, 라이센스(MIT?) 결정
  6. (선택) 디자이너 협업 — 자체 그리실 거면 Figma/Aseprite 학습. 아니면 외주.

위 1~5번 중 정하실 거 정해주시면 다음 단계로 가요. 특히 1번(픽셀 vs SVG)과 3번(기술 스택)이 우선이에요.
