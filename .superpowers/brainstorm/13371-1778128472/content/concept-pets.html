컨셉: 옆으로 나열된 펫 + 대화 채팅

세션 = 작은 카드, 카드 안에 펫(들). 단일 에이전트면 말풍선 1개, 서브에이전트 팀이면 채팅 대화. 길어지면 그 카드만 스크롤.

핵심 동작 정리

상황 표시
에이전트 1명, idle펫 큰 사이즈, "zzz..." 말풍선
에이전트 1명, 작업 중펫 큰 사이즈 + 도구명/내용 말풍선 (예: "📖 reading foo.ts")
에이전트 1명 → subagent 시작큰 펫 → 작은 채팅 모드로 전환, main + sub 두 줄
subagent 다수 (2+)계속 채팅. 새 메시지 = 자동 맨 아래로 스크롤
에러빨간 채팅 풍선, 카드 헤더 😰
권한 요청노란 채팅 풍선, 헤더 ⚠️ + 클릭 시 Allow/Deny
subagent 모두 종료채팅 → 다시 큰 펫 1마리로 복귀 (마지막 메시지는 말풍선으로)

구현 가능성

  • ✅ 옆으로 나열 + 가로 스크롤: flex + overflow-x
  • ✅ 각 카드 안 세로 스크롤: overflow-y: auto, 새 메시지마다 scrollTop = scrollHeight
  • ✅ 펫 종류 다양화: subagent마다 다른 동물 이모지/스프라이트 자동 할당 (해시 기반 → 같은 agent_id면 항상 같은 펫)
  • ✅ 데이터 출처: hook이 이미 session_id, subagent_id, tool_name, tool_input 다 줌
  • ⚠️ 메시지 텍스트는 hook 이벤트를 자연어로 변환 필요 (예: Bash + npm test → "⚡ npm test")
  • ⚠️ subagent의 "이름"은 hook에 안 나옴 — 자동 라벨(explorer-1, worker-A) 부여 필요

이 컨셉이면 Claude Pet의 옆으로 나열 + Clawd의 펫 캐릭터 + 채팅 비주얼 합친 형태예요. 이대로 갈까요? 아니면 펫 디자인이나 채팅 톤(이모지 vs 자연어 vs 둘 다)부터 더 구체화할까요?
