장단점 정리

장점

  • "각 세션 = 독립된 사무실"이 직관적 (격리감)
  • 층 단위로 스크롤 = 세션 많아져도 자연스럽게 확장
  • cwd/branch를 "사무실 간판"처럼 표시하면 디렉토리 구분 쉬움
  • subagent 수에 따라 1명/2명/팀 시각화가 자연스러움
  • 잘 알려진 메타포라 사용자가 첫 화면에서 바로 이해

단점

  • 세로로 길어서 가로 넓은 모니터에서 공간 낭비
  • 층마다 정보가 같아서 시각적 단조로움 가능 (해소: 층마다 다른 인테리어/색)
  • "빌딩"이 너무 무거운 메타포일 수도 (간단한 펫 → 진지한 회사 게임 분위기)
  • 픽셀 아트 어셋 비용: SimTower/Highrise 수준 만들려면 일러스트 작업 큼

변형 아이디어

  • 가로형 빌딩: 단면도 90도 회전 → 넓은 모니터 친화. 층 = 칸 (도시 거리뷰처럼)
  • 주상복합: 층마다 종류 다름. 사무실(작업) + 카페(휴식, idle 세션) + 옥상(권한 알림 모임)
  • 유리 빌딩: 미니멀 톤. 픽셀 대신 깔끔한 벡터로 → Clawd 스타일과 톤 맞춤

이 메타포가 끌리시면 더 구체적으로 들어갈게요 (예: 가로/세로 어느 쪽? 픽셀 vs 벡터? 어셈 톤?). 다른 메타포 더 보고 싶으면 말씀하세요.
