1. 한 줄 정의

Claude Code 세션을 옆으로 나열하는 SVG 펫 데스크탑 위젯. 세션 하나 = 펫 카드 한 장. 단일 에이전트는 큰 펫 + 말풍선, 서브에이전트가 도는 동안엔 그 카드가 펫들의 채팅창이 됨. 같은 프로젝트(git remote/cwd)는 이전 대화 자동 복원.

6. 합리적 기본값 (질문 안 하고 정한 것들)

  • 윈도우: frameless + transparent + always-on-top + draggable, 좌하단 시작, 위치 저장
  • 크기: 가로 풀폭, 세로 280px (카드 높이 240 + 헤더). 사용자 리사이즈 가능
  • 테마: 시스템 자동 (다크/라이트), 우클릭으로 강제 전환 가능
  • 권한 요청: 채팅 안 인라인 + 카드 헤더에 ⚠️ 배지. 클릭으로 Allow/Deny
  • Subagent 라벨: 해시 기반 동물 이름 (foxy, hammy 같은 식)
  • 지원 범위: Claude Code 만 (Codex/Gemini는 v2에서 검토)
  • 라이센스: MIT
  • 패키지: macOS DMG 우선, Win/Linux는 추후
